# SPY/QQQ DCA Reminder

这个项目在 GitHub Actions 上检查 SPY 和 QQQ，并通过 Telegram 发送定投提醒。当前 workflow 只保留 `workflow_dispatch`，由外部 cron-job 每 5 分钟触发；程序内部只在 NYSE 交易日的有效窗口内执行策略判断。

## 策略

- SPY 和 QQQ 独立判断、独立记录、独立发送消息。
- 每周基础提醒：每周第一个实际交易日开盘时段提醒一次；如果 Actions 延迟，当天交易时段内可补发一次。
- 单日下跌阶梯：
  - SPY：每下跌 1.5% 触发一个新阶梯。
  - QQQ：每下跌 2.0% 触发一个新阶梯。
  - 单日阶梯以上一交易日收盘价为初始基准，下一交易日重置。
- 单月下跌阶梯：
  - SPY：每下跌 5.0% 触发一个新阶梯。
  - QQQ：每下跌 7.0% 触发一个新阶梯。
  - 单月阶梯以上月最后一个交易日收盘价为初始基准，新自然月重置。
- 均线偏离：
  - SPY：低于 MA20 8.0%、低于 MA50 12.0%。
  - QQQ：低于 MA20 12.0%、低于 MA50 16.0%。
  - MA20 和 MA50 每月各最多提醒一次。
- 收盘总结：
  - 每日总结在 16:15 ET 后首次拿到有效收盘价时发送。
  - 每周总结在本周最后一个实际交易日每日总结后发送。
  - 月度总结在最后一个交易日的每日总结发送后发送。
  - 如果收盘价、MA20 或 MA50 尚未返回有效数值，跳过总结并等待下一轮重试。

## 数据口径

- 历史 OHLC 使用拆股复权、不分红复权口径。
- 不使用 `Adj Close` 作为触发基准，避免分红导致价格提醒误判。
- 上一交易日收盘价、上月最后交易日收盘价、MA20、MA50 和收盘总结使用同一价格尺度。
- 单日下跌的初始基准必须来自 NYSE 日历上的上一实际交易日；如果 yfinance 没有返回该日有效 `Close`，本轮跳过该标的，避免使用更早日期误触发。
- 收盘总结只在当日收盘价、MA20 和 MA50 均为有效有限数值时发送；遇到 `NaN` 或无效值会等待下一轮。
- 近30日涨跌幅按自然日向前 30 天取基准；如果当天不是交易日，则向前找最近交易日收盘价。
- Telegram 消息中的当日、当月、30日涨跌幅都会显示正负号和基准价，并使用短格式减少自动换行。
- Telegram 消息同时显示美东时间和北京时间。
- 每轮运行会输出非敏感诊断日志，包括当前价、昨收、单日触发线、当日涨跌幅和是否触发。

## GitHub Secrets

在仓库 `Settings > Secrets and variables > Actions` 添加：

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

不要把 token、chat id 或 `.env` 提交到仓库。

## 本地验证

```powershell
.\.venv\Scripts\python.exe -m pytest
```

只打印消息、不真实发送 Telegram：

```powershell
$env:DRY_RUN = "1"
.\.venv\Scripts\python.exe -m dca_reminder.main
```
